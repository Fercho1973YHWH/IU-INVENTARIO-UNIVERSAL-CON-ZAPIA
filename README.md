# IU Inventario Universal
App de inventario local para pequeños negocios.

La app guarda sus datos localmente. No desinstales ni borres datos para conservarlos. Las APK estables usan la clave privada de firma almacenada en los secretos del repositorio `ANDROID_KEYSTORE_BASE64` y `ANDROID_KEYSTORE_PASSWORD`; no reemplaces esa clave ni el ID de la app. El lector de códigos funciona con la cámara y requiere que los productos tengan una foto y un código EAN/UPC guardados. La foto es opcional, el código es lo que permite identificar el producto al escanear.
